# Minecraft Aim Trainer (Paper 1.21.4)

Paper 1.21.4向けに作成した、FPS風エイム練習用プラグインです。

## 主な機能

* 木のクワを銃として使用
* セミオート / フルオート切り替え
* ADS（エイム）機能
* リロード機能（31発仕様）
* リコイル・集弾率
* スコアシステム
* レベルアップするターゲット
* ターゲットHPバー表示
* ターゲットの左右移動
* `/lv <数字>` コマンドでターゲットレベル変更
* プレイヤー参加時に武器を自動配布
* クワ本来の耕作・攻撃動作を無効化

## 操作方法

| 操作        | 内容           |
| --------- | ------------ |
| 左クリック     | 射撃           |
| 右クリック     | ADS切り替え      |
| Fキー       | セミ/フルオート切り替え |
| Shift     | リロード         |
| 石のクワ右クリック | スコアリセット      |
| 金のクワ右クリック | ターゲットレベルリセット |

## レベルシステム

* ターゲット撃破でレベルアップ
* HPはレベルに応じて増加
* Lv50以降はターゲットの移動速度も上昇

## 動作環境

* Minecraft Java Edition 1.21.4
* Paper 1.21.4
* Java 21

※このプラグインは個人制作・学習目的で開発したものです。
